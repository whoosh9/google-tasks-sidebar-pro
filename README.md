
# Google Tasks Sidebar Pro

Access Google Tasks directly from your browser's side panel.

Google Tasks Sidebar Pro makes it easier to stay organized while browsing. View and manage your Google Tasks without switching tabs or interrupting your workflow.

## Features

- **Google Tasks in your sidebar** – Access your tasks alongside any website.
- **Google account selection** – Choose between Google accounts (Account 0–5).
- **Customizable themes** – Choose Light, Dark, or System default.
- **Local preferences** – Your account selection and theme preferences are saved locally in your browser.

## Installation

### Google Chrome

1. Download the latest ZIP package from [GitHub Releases](https://github.com/whoosh9/google-tasks-sidebar-pro/releases).
2. Extract the ZIP file to a folder on your computer.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the folder containing `manifest.json`.

### Microsoft Edge

1. Download the latest ZIP package from [GitHub Releases](https://github.com/whoosh9/google-tasks-sidebar-pro/releases).
2. Extract the ZIP file to a folder on your computer.
3. Open `edge://extensions` in Edge.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the folder containing `manifest.json`.

## Requirements

- Google Chrome or Microsoft Edge with Side Panel support.
- A Google account with access to Google Tasks.
- An active Google sign-in session in your browser.

## Privacy

The extension stores your selected Google account index and theme preference locally in your browser. It does not collect or transmit this preference data to the developer.

Google Tasks is loaded directly from Google's website.
